## LOD2を実際に使った範囲

`udx/bldg/50326611_bldg_6697_op.gml` 内の建物ID `bldg_adf19f2c-f291-4b52-b75f-f883ce5c8e3e` を抽出した。これは大天守だけでなく、連立天守群を含む建物である。

抽出対象は `boundedBy / lod2MultiSurface` の471ポリゴン。LOD0屋根外周の標高0は混入させない。原座標はEPSG:6697。緯度33.8455・経度132.76572、原標高131.72277507mを表示原点とし、局所接平面近似で東・上・南のメートル座標へ変換した。縮尺のフィッティングは行っていない。外周だけでなく内周リングも保持し、穴を考慮して三角形化する。

原ポリゴンは `public/data/plateau-castle-lod2.json` に保存。抽出スクリプトは `scripts/extract-plateau.py`、モデル生成は `src/plateau.mjs` / `scripts/build-plateau-model.mjs`。元データは配布ZIPから指定メッシュを取り出して再抽出できる。メッシュSHA-256は抽出JSONに収録。

**公式由来なのは外形ポリゴンであり、追加の瓦・窓格子・配色・材質はCの視覚的補完。** 特に窓はLOD2壁面上の装飾で、公式に測定された窓位置や開口を表さない。装飾は `*_C`、公式面は `Surveyed*` のノードとして分離している。

## 散歩用モデルの改修

公式写真の正面で確認できる下段三角破風、中段唐破風、白い軒裏と垂木、最上階外周の高欄を反映。破風縁は厚み・段差を持たせ、屋根は反りと分割丸瓦・重なり・軒先端部・棟の積み重ねを追加した。窓台・窓枠・建具金物、梁の接合部と木栓、石材の角欠けと乾式目地を加えた。

正確な破風の彫刻、鯱・鬼瓦の意匠、個々の石の割付や室内の座標は確定していない。装飾密度を増やしたことを、実物の測量精度向上とは扱わない。

## 内外装のPBR

木材・漆喰・石・瓦・地面・鉄の6系列に色・法線・粗さの3マップを生成。すべて `scripts/generate-materials.py` による数学的合成。写真画素、AI画像、出典不明の素材サイトは使用しない。

木目UVは柱・梁・床の長手方向に合わせる。石材と板材は部品単位の色差を持つ。GLB内にPNGを埋め込むので、Web専用シェーダーに依存せず、外部glTFビューアーでも材質を利用できる。写真から測定した物理的反射率ではない。

## 表示と操作

- 通常の「散歩をはじめる」：開口と階段を持つ推定の散歩用モデル。
- 「PLATEAUの外観を見る」：別の公式LOD2由来外観を必要時に読み込み、ドラッグで回転、ホイール等で拡大。
- 外観表示から散歩を開始すると推定モデルへ切り替わる。**実測内外一体のシームレスモデルではない。** LOD2には内部データがなく、両者の対応を測定したふりをしない。

## 検査

`npm test`：従来の歩行・衝突・精度制約に加え、LOD2面・内周・標高・出典、全素材のSHA-256を検査。

`npm run build`：両GLBと本番サイトを再生成。

`node scripts/check-reproducibility.mjs`：両GLBのバイト一致再生成。

`python3 scripts/inspect_model.py`：実際にGLBへ入ったPNGのハッシュを独自素材台帳と照合、PBRの存在と本番テストAPI非露出を検査。

ブラウザー・CIの最終実行状況はPRとワークフローの結果を参照。実機iPhone/iPad Safariの確認とは区別する。
