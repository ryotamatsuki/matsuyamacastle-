# 復元精度・推定台帳

更新日: 2026-09-15

本コンテンツは文化財の測量データそのものではなく、権利条件を確認した公開資料と、明示した推定から生成する3D復元です。

## 判定定義

- **A-ratio**: 公的資料に直接記載された間単位の寸法比率。メートル座標がAになることを意味しない。
- **B**: 複数の独立した Public Domain / CC BY 資料と公的事実記述から、形態・存在・関係を相互確認できるもの。
- **C**: 推定、未登録の写真測量、ゲームプレイ補間、または証拠不足。

**モデル全体および正確な内部ジオメトリは引き続き C。** 今回Bへ昇格したのは、複数の再利用可能資料で相互確認できた「形態・関係」の一部だけである。Bはsurvey-gradeを意味しない。

## 写真資料の利用境界

写真は壁・床・建具のテクスチャとして一切使用しない。利用するのは、権利確認済み資料から読み取れる建築形態の観察だけである。人物、甲冑等の展示、説明板、現代写真・絵画等はモデル化しない。

採用写真・作者・URL・ライセンス・archive URL・既知のファイルhashは `public/data/source_manifest.json` を参照。部位別の独立証拠とB判定理由は `docs/INTERIOR_EVIDENCE_MATRIX.md` を参照。

## 写真測量の未達範囲

現段階では、権利確認済み複数写真について同一柱・同一窓を厳密に対応させ、消失点・カメラ姿勢・既知寸法を用いて柱芯や階段位置を数値復元する工程は未完了である。そのため、見えない領域やexact coordinatesをBへ上げない。

## 生成物への精度情報

`src/data/interiorEvidence.mjs` が証拠の正本、`src/data/castleDimensions.mjs` が現行ジオメトリ入力である。GLB root extrasには evidence version、B-grade scope、source IDs、overall Cを埋め込む。`scripts/inspect_model.py` がその境界をCIで検証する。

手摺や衝突判定は安全に歩くための表現であり、文化財本体に同じ設備・位置が存在すると主張しない。
