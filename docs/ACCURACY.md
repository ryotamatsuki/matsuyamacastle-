# 復元精度・推定台帳
本コンテンツは文化財の測量データそのものではなく、公開オープンデータと歴史資料を基にした3D復元です。
初版の実際の入力はCITY-KEEPの事実記述のみです。外部のオープン3Dモデルや写真は取り込んでいません。

A = 公開3Dデータまたは明示寸法に直接対応。B = 複数のPD / CC BY写真と公式記述から再構築。C = 歩行体験のための推定復元。
モデル全体はC。Bの認定項目はありません。Aの寸法比率が含まれても、メートル単位のメッシュが測量精度Aになるわけではありません。

| 部位・事項 | 根拠・拘束 | 判定・推定 |
|---|---|---|
| 再建年代 | CITY-KEEP、1852年 | 年代上の事実。ジオメトリ精度とは別 |
