# PLATEAU外形と内部を接続する散歩モデル

散歩・見渡しは同一の `matsuyama_keep.glb` を使用します。見渡しボタンはカメラ操作だけを切り替え、建物を交換しません。旧来の独立した復元建物、仮の付属棟配置、正面階段、本丸床、仮の街並みを散歩から外しました。

## 座標と根拠

PLATEAUの連立天守群471面を元の縮尺で使用します。原点は緯度33.8455、経度132.76572、標高131.72277507m。東・上・南のメートル座標です。PLATEAUは現地の完全な測量再現を保証するものではなく、公開LOD2の外形を基準とします。

大天守下層は p23809、中層は p23805、上層は p23802 の外壁位置を参照。上階ほど床を縮小し、大天守座標系を約0.86度回転させています。床の縁は壁厚分だけ内側に寄せます。柱の基本軸組は上層に揃え、梁・内壁・階段・床開口をこの枠内に配置します。LOD2から室・柱・階段を取得したものではありません。

**階高・壁厚・内庭高さ9.2mはC推定**です。外壁の段・屋根に収まる高さを採用しており、測量済みの階高ではありません。内庭の平面境界はPLATEAU GroundSurfaceの内周から取得しました。外の広域地面は原点高さの参考平面で、山の標高モデルではありません。

## 入口と窓

松山市公式解説の「内庭に面する入口」、鉄板扉、穴蔵の敷瓦、木造階の窓・塗籠格子・建具構成を参照。既存の権利確認済み公開写真を形態参照に使っています。

外壁は入口・窓の直方体との交差部分を三角形単位で取り除きます。同じ開口定義で内壁を分割し、敷居・見込み・枠・格子を生成します。透明な板や黒い窓デカールだけで開口を装う方式ではありません。窓の下部には壁が残り、歩行者は窓から落下しません。

入口の採用幅2.6m・高さ2.95m、各窓の幅1.32m・高さ最大1.5m、窓数・正確な割付座標は**C補間**です。写真で全bayを測定・登録したという意味ではありません。写真・公式記述が裏付ける形態／内庭との関係と、未測定の位置寸法を区別します。内部階段の位置・方向・勾配もCです。

## 本丸広場から本壇への接続

松山市の公式説明では、一ノ門は本壇入口に西面し、一ノ門と二ノ門の間は枡形を構成します。一ノ門内で左折し、九段の石段を上ると二ノ門に至り、その後、三ノ門を経て天守石垣下を右折すると筋鉄門から内庭へ入ります。また本壇は本丸より約8m高いとされています。

この関係を優先し、**本丸広場から本壇へ上がる部分を「正面に露出した長大な階段」としては表現しません。** 旧実装で用いていた39段の下部補間階段は、連続歩行を成立させるだけのC補間であり、史実の段数を示すものではありませんでした。そのため撤去しました。

現在は、PLATEAU/GSIの水平位置と内庭9.2m・本丸側ほぼ0mの既存datumを維持したまま、下部の高低差を**本壇西側に寄せた狭い連続勾配**で吸収します。勾配の両側にはC推定の石垣状保持体を置き、PLATEAUの本壇石垣へ視覚的に連続させます。広場から見ると、独立した巨大階段が天守正面へ突出するのではなく、石垣に収まった取付路として見えることを狙います。

公式記述で段数を確認できる**二ノ門付近の九段だけ**を、段数を持つ明示的な石段として残します。下部取付路の平面位置、幅、勾配、保持石垣の形状、一ノ門の正確な門芯はいずれもCです。これは実測復元ではなく、公式の門関係とPLATEAU外形を矛盾させず連続歩行させるための保守的な補間です。詳細は `public/data/hondan-route-evidence.json` に記録します。

## 歩行との一致

PLATEAU壁・屋根の開口加工後の三角形から衝突面を作成。内壁・柱・手摺も描画と同じ寸法定義を使用。床・階段開口・歩行用斜面も共通の階定義を使用します。内部階段の踏面は32段、歩行判定は滑らかな斜面という操作上の近似です。

本丸広場側の取付勾配も描画と歩行判定で同じデータを使用します。推定保持石垣は描画だけでなく歩行上もsolidです。内庭→本壇門群の推定経路→本丸広場、およびその逆方向を途中の座標移動なしで検証します。

## 材質と航空写真

既存18枚の自作PBRマップ（木、漆喰、石、瓦、土、鉄の色・法線・粗さ）と生成方法を維持。建築物と推定石垣にはこの素材を埋め込み、既存の瓦細部をPLATEAU屋根に重ねます。

屋外は[地理院タイル・全国最新写真（シームレス）](https://maps.gsi.go.jp/development/ichiran.html#seamlessphoto) のz18を9枚使用。2026-09-15取得。タイルの経緯度角をPLATEAUと同じ接平面へ変換して投影します。画像には撮影時の屋根・樹木・影も含まれます。航空写真から地形標高を推定したものではありません。

表示する出典：**地理院タイル（全国最新写真・シームレス）を加工して作成**。
[国土地理院コンテンツ利用規約](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html) および配信仕様を確認。該当高倍率写真は出典記載で利用可能な区分。松山城は追加GRUSクレジット対象範囲外。URL・SHA256・取得画像そのものを `public/data/aerial-tiles.json` に固定し、ブラウザ実行時の国土地理院への通信依存をなくしています。

PLATEAU／権利確認済み写真／GSI画像／自作素材を `source_manifest.json` 等で区分して記録し、GSI画像を自作素材として表記しません。写真は画像貼付ではなく形態参照に限定します。原出典・作者・ライセンス・加工内容を出典パネルに記載しています。
